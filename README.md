# mbatraining

Cuaderno interactivo de Fundamentos de Economía. Abre [index.html](index.html) en un navegador con JavaScript activado. El sitio funciona sin instalación, backend ni conexión a Internet. Conserva la estructura de la carpeta para que el navegador encuentre los gráficos, los datos del curso y el PDF a color.

1. Elige un módulo y un apartado. Lee las ideas clave y consulta sus gráficos.
2. En cada pregunta de comprensión puedes elegir una opción o escribir tu propia respuesta. En la pregunta de desarrollo, redacta un texto de unas 100 palabras.
3. Para contrastar una respuesta, despliega la solución en esa pregunta o abre el **Solucionario** para consultar las 510 respuestas de comprensión y los 102 modelos de desarrollo. Consultar una solución conserva tu respuesta y tu puntuación.
4. En **Mis respuestas**, revisa cuántas opciones has acertado. Cada elección correcta vale un punto, hasta 510 en el curso. El porcentaje de acierto se calcula sobre las preguntas que has contestado eligiendo una opción. Si cambias una respuesta, el resultado refleja la opción actual. Las respuestas en texto libre, incluidas las de desarrollo, quedan para revisión.
5. Descarga **Word (.docx)** para leer o compartir el cuaderno, o **JSON** para evaluar los datos por pregunta. Ambos incluyen el resultado automático. Puedes incluir las respuestas de referencia del solucionario y adjuntar el archivo a la IA que elijas para que valore tus respuestas escritas.

El progreso se guarda en el almacenamiento local del navegador cuando está disponible. Vuelve a abrir el cuaderno con el mismo navegador y perfil. Un cambio de ruta al abrir archivos locales, o de origen si sirves la web (protocolo, dominio o puerto), puede mostrar un cuaderno distinto. Si vas a mover la carpeta o borrar los datos del navegador, descarga antes tus respuestas.
